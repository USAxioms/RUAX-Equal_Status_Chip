5. TEST SUITE DESCRIPTION
================================================================================

The reproducibility capsule includes 10 comprehensive tests:

  [TEST 1]  Basic Operation Acceptance
            Verifies that operations are correctly admitted when all
            predicates are satisfied.

  [TEST 2]  Identical Signatures, Identical Decisions
            Verifies Axiom A1: operations with identical perturbing
            signatures must receive identical decisions.

  [TEST 3]  Refusal Consistency
            Verifies Axiom A2: once an operation is refused, all
            future operations with the same perturbing signature are
            refused (monotonic refusal).

  [TEST 4]  Registry Monotonicity
            Verifies Axiom A3: the perturbing set can only grow
            (bitwise OR), never shrink.

  [TEST 5]  Cache Effectiveness
            Verifies that the pair-matcher cache correctly stores
            and reuses decisions for identical signatures.

  [TEST 6]  Non-Discrimination on Identity (Corollary C1)
            Verifies that operations differing only in requester ID
            receive identical decisions (if requester is not perturbing).

  [TEST 7]  Discrimination When Requester Marked Perturbing
            Verifies that once requester is marked as perturbing,
            different requesters produce different signatures.

  [TEST 8]  Monotonic Tightening
            Verifies that the registry register can only add bits
            (OR operation), not remove them.

  [TEST 9]  Cache Collision Handling
            Verifies that hash collisions in the cache do not
            violate the invariant (exact signature matching).

  [TEST 10] WAD-18 Fixed-Point Arithmetic
            Verifies that the WAD-18 fixed-point arithmetic
            (1 WAD = 10^18) produces correct results.

9. REFERENCE IMPLEMENTATION FEATURES
================================================================================

The equal_status_ref.c implementation includes:

  1. Field-Classifier
     - Computes XOR of selected fields based on perturbing mask
     - Combinational logic (no state)

  2. Pair-Matcher
     - 64-entry cache indexed by hash of perturbing signature
     - Tracks (signature, decision, valid) tuples
     - Simple hash: signature & 0x3F (lower 6 bits)

  3. Discrimination-Detector
     - 64-bit refusal tracker (one bit per cache slot)
     - Monotonically set (never cleared)
     - Enforces refusal consistency

  4. Registry-Controller
     - 32-bit register for perturbing set
     - OR-only updates (bitwise OR)
     - No subtraction or removal operations

  5. Predicate Combiner
     - Combines permission and epoch decisions via AND
     - Forwards to cache for reuse


10. TROUBLESHOOTING
================================================================================

Problem: Compilation fails with "undefined reference to main"
  Solution: Ensure equal_status_ref.c is included, not just a header file

Problem: Tests fail with "Assertion failed"
  Solution: Check the output for specific test failure. Review the test code
            and the corresponding axiom in Doc_0.

Problem: Slow performance (< 1000 ops/sec)
  Solution: Compile with -O2 or -O3 flag (enabled by default in Makefile)

Problem: Cache hit rate is very low (< 80%)
  Solution: This is normal if perturbing set is large or operations are diverse.
            To diagnose, print the perturbing set and operation signatures.
