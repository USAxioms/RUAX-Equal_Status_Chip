Formal specification and silicon-ready implementation of the Equal-Status 
Memory Controller—a cache-based hardware controller enforcing 
non-discrimination at the memory boundary via four axioms (A1-A4). Includes 
four-tier formal specs (Doc_0-3), 15 SVA properties, C99 reference 
implementation (10/10 tests pass), JasperGold/VC Formal scripts, and complete 
TSMC 28nm manufacturing documentation. APPROVED FOR TAPEOUT.
